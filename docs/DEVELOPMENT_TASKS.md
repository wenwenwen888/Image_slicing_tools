# 开发任务拆分

## 1. 开发原则

- 先做可用闭环，再做高级能力。
- 先完成网页端核心，再接桌面端能力。
- UI 保持简单，优先清楚和稳定。
- 图片处理逻辑与界面分离，方便 Web 和桌面复用。
- 平台 icon 规格用配置驱动，避免写死在组件里。

## 2. 阶段 0：项目初始化

### T0.1 初始化前端工程

- 创建 Vite + React + TypeScript 项目。
- 配置基础代码格式化。
- 配置基础目录结构。
- 配置开发、构建、预览命令。
- 添加基础页面骨架。

验收标准：

- 本地可以启动开发页面。
- 页面能显示应用主布局。
- 构建命令可以成功执行。

### T0.2 建立基础文档目录

- 创建 `docs/` 目录。
- 移动或复制产品需求文档。
- 放入技术栈建议文档。
- 放入开发任务拆分文档。

验收标准：

- 文档集中在 `docs/` 下。
- 后续开发能按文档追踪任务。

## 3. 阶段 1：基础 UI 和图片导入

### T1.1 主界面布局

- 实现顶部工具栏。
- 实现左侧工具栏。
- 实现中央画布区域。
- 实现右侧属性面板。
- 实现底部状态栏。
- 状态：已完成。

验收标准：

- 页面结构完整。
- 窗口缩放时布局不乱。
- 画布区域占据主要空间。

### T1.2 图片导入

- 支持点击按钮选择图片。
- 支持拖拽图片导入。
- 支持 PNG、JPG/JPEG、WebP。
- 显示图片基础信息。
- 处理不支持格式和解析失败。
- 状态：已完成。

验收标准：

- 用户能导入本地图片。
- 图片能显示在画布中。
- 错误文件有明确提示。

### T1.3 画布显示

- 图片居中显示。
- 支持适应窗口。
- 支持 100% 显示。
- 支持放大和缩小。
- 支持拖动画布。
- 显示透明棋盘格背景。
- 状态：已完成。

验收标准：

- 大图和小图都能合理显示。
- 缩放和拖动操作流畅。
- 状态栏显示当前缩放比例。

## 4. 阶段 2：矩形切图闭环

### T2.1 矩形选区工具

- 支持拖拽创建矩形选区。
- 支持移动选区。
- 支持拖拽边角调整尺寸。
- 支持删除选区。
- 支持选中状态展示。
- 状态：已完成。

验收标准：

- 用户可以手动框出图片任意区域。
- 选区坐标和尺寸准确。
- 选区不能异常丢失。

### T2.2 属性面板编辑

- 显示当前选区名称。
- 显示 X、Y、宽、高。
- 支持输入数值精确调整。
- 支持锁定比例。
- 支持启用或禁用导出。
- 状态：已完成。

验收标准：

- 修改输入框后画布选区同步变化。
- 拖动画布选区后属性面板同步变化。

### T2.3 切片列表

- 展示所有切片。
- 显示名称、尺寸、启用状态。
- 支持重命名。
- 支持删除。
- 支持点击定位。
- 状态：已完成。

验收标准：

- 多个选区可以统一管理。
- 列表状态和画布状态一致。

### T2.4 撤销重做

- 支持创建选区撤销。
- 支持移动和缩放撤销。
- 支持删除撤销。
- 支持重做。
- 状态：已完成。

验收标准：

- 连续操作可以正确撤销和重做。
- 撤销后画布、列表、属性面板一致。

## 5. 阶段 3：基础导出

### T3.1 单切片导出

- 支持导出当前选区。
- 支持 PNG。
- 支持 JPG/JPEG。
- 支持文件名设置。
- 支持 WebP。
- 状态：已完成。

验收标准：

- 导出图片尺寸与选区一致。
- PNG 可以保留透明通道。
- JPG 可设置背景色或默认白底。

### T3.2 多切片批量导出

- 支持导出全部启用选区。
- 支持自动编号。
- 支持文件名前缀。
- 支持重名处理。
- 支持 ZIP 打包。
- 状态：已完成。

验收标准：

- 多个切片可以一次导出。
- 导出数量与启用切片数量一致。
- 文件名不冲突。

### T3.3 导出前检查

- 检查空选区。
- 检查超出图片边界。
- 检查尺寸异常。
- 检查重名。
- 状态：已完成增强版。当前浏览器下载模式会自动生成安全文件名，多文件导出使用 ZIP 避免同目录重名覆盖；导出面板会预览包名、文件数量、示例路径和平台风险提示。

验收标准：

- 问题能在导出前提示。
- 用户能继续调整后重新导出。

## 6. 阶段 4：Web icon 尺寸导出

### T4.1 Web icon 预设

- 添加 favicon 尺寸：16、32、48 px。
- 添加 PWA 尺寸：192、512 px。
- 添加 Apple touch icon 常用尺寸。
- 添加 maskable icon 选项。
- 状态：已完成。

验收标准：

- 用户选择 Web 预设后能看到导出尺寸清单。
- 同一个 icon 能导出多种尺寸。

### T4.2 Web 资源包

- 支持输出多尺寸 PNG。
- 支持生成 manifest icons 片段。
- 支持生成 HTML link 片段。
- 支持 ZIP 打包。
- 状态：已完成。

验收标准：

- ZIP 内文件结构清晰。
- 生成的配置片段和文件名一致。

## 7. 阶段 5：固定尺寸和网格切图

### T5.1 固定尺寸切图

- 支持输入切片宽高。
- 支持输入起始 X、Y。
- 支持输入行列数量。
- 支持输入横向和纵向间距。
- 状态：已完成。

验收标准：

- 系统能生成固定尺寸选区。
- 用户可以调整参数并实时预览。

### T5.2 网格切图

- 支持按行列均分。
- 支持按单元格尺寸生成网格。
- 支持排除指定格子。
- 支持按行优先或列优先编号。
- 状态：已完成基础版。当前通过生成普通切片后，在切片列表中禁用或删除指定格子来完成排除。

验收标准：

- 网格预览与最终导出一致。
- 排除的格子不会导出。

### T5.3 形状和固定比例切图

- 支持矩形、圆角矩形、圆形/椭圆切片。
- 支持设置新建切片默认形状。
- 支持圆角半径设置。
- 支持自由、1:1、4:3、16:9、3:2 绘制比例。
- 支持固定比例下创建和缩放切片。
- 导出时按切片形状裁剪，PNG/WebP 可保留透明外圈，JPG 使用背景色填充。
- 状态：已完成基础版。当前支持圆角矩形、圆形/椭圆和固定比例；多边形、自由路径和形状布尔运算留到后续高级形状工具。

验收标准：

- 画布预览形状与导出裁剪一致。
- 固定比例创建和缩放时不会超出图片范围。

## 8. 阶段 6：桌面端 Tauri

### T6.1 接入 Tauri

- 初始化 Tauri 2。
- 复用现有 Web 页面。
- 配置 macOS 和 Windows 基础窗口。
- 配置应用名称和图标。
- 状态：已完成基础接入。当前已添加 `src-tauri`、Tauri 配置、Rust 入口、桌面开发/构建脚本；应用图标待后续生成正式资源。

验收标准：

- macOS 可以运行桌面端。
- Windows 构建流程有明确配置。

### T6.2 桌面文件能力

- 支持系统文件选择器打开图片。
- 支持选择导出目录。
- 支持批量写入本地文件。
- 支持打开导出目录。
- 状态：已完成增强版。当前 Tauri 环境中支持系统文件选择器打开图片，导出时可选择 ZIP 或桌面文件夹；文件夹导出会按 Android/iOS/Web/自定义资源包结构批量创建子目录并写入文件，导出后可打开最近一次导出目录。

验收标准：

- 桌面端不依赖浏览器下载机制。
- 用户可以直接导出到指定文件夹。

## 9. 阶段 7：Android / iOS icon 导出

### T7.1 Android 资源包

- 支持 `mdpi`、`hdpi`、`xhdpi`、`xxhdpi`、`xxxhdpi`。
- 支持 `mipmap-*` 目录。
- 支持 `drawable-*` 目录。
- 支持资源文件名校验。
- 支持 Legacy Launcher Icon 常用尺寸。
- 状态：已完成增强版。当前输出 `mipmap-*` Legacy Launcher Icon 尺寸，并额外生成 Adaptive Icon foreground、`mipmap-anydpi-v26` XML 和默认背景色资源；资源名支持校验和自动清理。`drawable-*` 目录选择留到后续增强。

验收标准：

- Android 资源目录结构正确。
- 资源文件尺寸正确。
- 非法文件名会被提示或自动修正。

### T7.2 iOS 资源包

- 支持生成 `AppIcon.appiconset`。
- 支持生成 `Contents.json`。
- 支持 1024 px 主图。
- 支持 `@1x`、`@2x`、`@3x` 命名规则。
- 支持透明背景检查。
- 状态：已完成增强版。当前可生成 `AppIcon.appiconset`、`Contents.json`、常用 iPhone/iPad/App Store 尺寸；当原图包含透明通道时，导出预览会提示检查 App Icon 背景。

验收标准：

- 生成结果可以被 Xcode Asset Catalog 识别。
- 尺寸和配置文件一致。

## 10. 阶段 8：智能识别 icon

### T8.1 透明背景识别

- 扫描 alpha 通道。
- 识别非透明连通区域。
- 过滤小噪点。
- 自动生成包围盒。
- 支持扩展边距。
- 支持疑似文字区域过滤。
- 支持邻近区域合并和断裂区域桥接。
- 状态：已完成增强版。当前可按透明阈值扫描非透明连通区域，支持 8 邻域连接、桥接间隔、邻近/同行合并、文字区域开关过滤，并先生成可删除误识别项的预览候选；也支持对当前切片或全部未锁定切片按透明像素边界自动收紧。

验收标准：

- 对透明背景 icon 合集能识别主要图形。
- 用户可以编辑识别结果。

### T8.2 纯色背景识别

- 支持点击选择背景色。
- 支持颜色容差。
- 支持主体区域识别。
- 支持噪点过滤。
- 支持点击画布取样背景色。
- 状态：已完成增强版。当前支持选择背景色、点击画布取样背景色、设置颜色容差、最小面积、最小边长和扩展边距，并通过预览候选过滤误识别区域后再替换或追加到正式切片。

验收标准：

- 白底或纯色底 icon 合集能得到可用识别结果。
- 识别参数调整后结果会更新。

## 11. 阶段 9：项目文件和预设

### T9.1 保存项目

- 保存原图引用。
- 保存所有选区。
- 保存导出设置。
- 保存平台预设选择。
- 状态：已完成基础版。当前支持保存和打开 `.ist-project.json` 项目文件，项目内包含图片数据、切片、当前选区、导出设置、网格参数、识别参数和自定义尺寸预设；后续可增强为引用原图路径或桌面端项目目录。

验收标准：

- 关闭后重新打开项目能恢复工作状态。

### T9.2 自定义平台预设

- 支持新增自定义尺寸包。
- 支持编辑尺寸、目录、文件名。
- 支持导入和导出 JSON。
- 状态：已完成基础版。当前导出设置中新增“自定义”平台，可新增、编辑、删除、启用尺寸，支持单独打开和保存自定义预设 JSON，并在导出 ZIP 中附带 `custom-preset.json`。

验收标准：

- 用户可以保存自己的项目规格。
- 同一规格可以复用到不同图片。
