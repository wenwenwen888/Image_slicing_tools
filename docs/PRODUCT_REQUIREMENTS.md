# 跨平台图片切图工具产品需求文档

## 1. 产品概述

本项目计划构建一款可在 macOS、Windows 和网页端运行的图片切图工具，面向设计师、前端工程师、游戏美术、运营人员、图标整理人员、素材处理人员等用户。

工具支持导入 PNG、JPG/JPEG 等常见图片格式，并提供多种切图方式，包括手动框选、智能识别 icon、按自定义图形裁切、按固定尺寸或网格批量裁切、按透明区域或视觉边界自动裁切等。用户可以在可视化画布中完成选择、预览、命名、导出和批处理。

产品目标不是只做一个简单裁剪器，而是做一个“图片素材拆解与导出工作台”：让用户能够快速从整张 UI 截图、设计稿导出图、雪碧图、图标合集、游戏素材图或营销图片中提取可复用的小图资源。

## 2. 产品目标

### 2.1 核心目标

- 支持 macOS、Windows 和网页端使用，保持一致的核心体验。
- 支持 PNG、JPG/JPEG 等主流图片格式导入与导出。
- 支持单张图片切图和多张图片批量处理。
- 支持手动、半自动和智能化多种切图方式。
- 支持精确控制切图区域、尺寸、比例、边距、命名和导出格式。
- 支持非专业用户快速上手，也支持专业用户高效率处理大量素材。

### 2.2 体验目标

- 打开图片后，用户应能在 3 秒内理解如何开始切图。
- 手动选区应足够顺滑，支持拖拽、缩放、吸附、微调。
- 智能识别结果应可编辑，而不是黑盒自动导出。
- 导出前应有清晰预览，避免切错、漏切、命名混乱。
- 大图、多图、透明图、图标合集等复杂场景下仍保持稳定。

## 3. 目标用户

### 3.1 设计师

- 从设计稿导出的整图中拆分 icon、插图、按钮状态图。
- 批量导出不同尺寸的素材。
- 快速检查透明边距、图标留白、尺寸一致性。

### 3.2 前端工程师

- 从 UI 截图或旧项目资源中提取图标和图片资产。
- 批量生成 Web 需要的 PNG、JPG、WebP 等资源。
- 导出时自动生成合理文件名，减少手动整理成本。

### 3.3 游戏美术与独立开发者

- 从 sprite sheet 中按网格或自动识别方式切出帧图。
- 按固定尺寸切割角色动作、道具、特效素材。
- 导出帧序列并保持编号顺序。

### 3.4 运营和内容人员

- 从长图、海报、活动图中截取局部元素。
- 按固定比例裁出社交媒体、广告位、商品图。
- 使用简单模式完成常见裁切，不需要理解复杂参数。

## 4. 支持平台

- 支持保存默认导出目录。
- 支持快捷键、触控板缩放、鼠标滚轮缩放。

### 4.2 Windows 桌面端

- 支持拖拽图片到窗口导入。
- 支持系统文件选择器打开图片。
- 支持常见 Windows 快捷键习惯。
- 支持高 DPI 屏幕显示。

### 4.3 网页端

- 支持浏览器本地导入图片处理。
- 默认不上传原图，保护隐私。
- 支持下载单个文件或打包 ZIP。
- 支持主流浏览器：Chrome、Edge、Safari、Firefox。

- 导出尺寸缩放，例如 1x、2x、3x。

## 7. 核心工作流

### 7.1 单图手动切图流程

1. 用户导入图片。
2. 图片显示在画布中央。
3. 用户选择“矩形框选”工具。
4. 用户拖拽生成选区。
5. 用户通过拖拽边角、输入数值或方向键微调选区。
6. 用户为选区命名或使用自动命名。
7. 用户点击导出，保存选中区域。

### 7.2 智能识别 icon 流程

1. 用户导入包含多个 icon 的图片。
2. 用户点击“智能识别”。
3. 系统分析图片中的独立图形、透明区域、边缘和视觉间距。
4. 系统生成多个候选切图区域。
5. 用户检查识别结果，删除误识别区域，合并或拆分区域。
6. 用户统一设置边距、尺寸和命名规则。
7. 用户批量导出。

### 7.3 固定尺寸批量切图流程

1. 用户导入图片。
2. 用户选择“按尺寸切割”。
3. 用户输入宽度、高度、起始位置、间距和行列数量。
4. 系统在画布上生成网格预览。
5. 用户调整偏移、间距或排除某些格子。
6. 用户批量导出。

### 7.4 自定义图形切图流程

1. 用户选择图形工具。
2. 用户绘制圆形、椭圆、多边形、自由路径或预设形状。
3. 系统按图形边界生成裁切结果。
4. 用户选择透明背景、填充背景或保持原矩形画布。
5. 用户导出切图。

### 8.1 手动矩形切图

- 支持拖拽创建矩形选区。
- 支持移动选区。
- 支持调整宽高。
- 支持锁定比例。
- 支持从中心缩放。
- 支持像素级微调。
- 支持输入 X、Y、宽、高。
- 支持复制选区。
- 支持删除选区。
- 支持多选区同时导出。

### 8.2 手动自由选区

- 支持自由套索。
- 支持多边形套索。
- 支持闭合路径裁切。
- 支持羽化边缘，作为高级选项。
- 支持将自由选区导出为透明背景 PNG。

### 8.3 固定尺寸切图

- 支持输入固定宽度和高度。
- 支持设置起始 X、Y。
- 支持设置横向间距和纵向间距。
- 支持设置行数和列数。
- 支持自动铺满整张图。
- 支持跳过空白区域。
- 支持排除指定格子。
- 支持按行优先或列优先编号。

### 8.4 网格切图

- 支持按行列均分。
- 支持按固定单元格尺寸生成网格。
- 支持显示网格线。
- 支持拖动网格整体偏移。
- 支持调节网格间距。
- 支持吸附图片边界。

### 8.5 智能识别 icon

- 支持识别透明背景上的独立图形。
- 支持识别纯色或近似纯色背景上的图形。
- 支持识别间隔明显的图标合集。
- 支持自动生成包围盒。
- 支持设置最小识别尺寸。
- 支持设置最大识别尺寸。
- 支持设置识别灵敏度。
- 支持设置识别后自动扩展边距。
- 支持合并距离过近的区域。
- 支持拆分误合并的区域。
- 支持过滤面积过小的噪点。

### 8.6 按透明区域自动裁切

- 支持自动去除四周透明边距。
- 支持批量对所有切片去透明边。
- 支持保留指定安全边距。
- 支持按 alpha 阈值判断透明。

### 8.7 按颜色区域裁切

- 支持点击选择背景色。
- 支持容差设置。
- 支持按颜色连通区域识别主体。
- 支持去除单色背景后裁切。

### 8.8 自定义形状裁切

- 支持圆形。
- 支持椭圆。
- 支持圆角矩形。
- 支持多边形。
- 支持星形、三角形等预设图形。
- 支持用户导入 SVG 作为裁切蒙版，作为高级功能。
- 支持反向裁切，作为高级功能。

### 8.9 按比例裁切

- 支持 1:1。
- 支持 4:3。
- 支持 16:9。
- 支持 3:4。
- 支持 9:16。
- 支持自定义比例。
- 支持固定比例下调整裁切框。

### 8.10 批量自动切图

- 支持多张图片使用同一套切图规则。
- 支持将当前选区模板应用到其他图片。
- 支持对文件夹内图片批量裁切。
- 支持批量导出进度显示。
- 支持失败记录和重试。

## 9. 画布与交互需求

### 9.1 画布基础操作

- 支持放大、缩小。
- 支持适应窗口。
- 支持 100% 原始尺寸查看。
- 支持拖动画布。
- 支持显示透明棋盘格背景。
- 支持切换深色、浅色画布背景。
- 支持标尺。
- 支持参考线。
- 支持网格辅助线。

- 拖拽选区时显示实时坐标。

- 支持方向键移动 1px。

- 支持排序。
- 支持分组。

- 支持复制、删除、合并。
- 支持点击列表项定位到画布选区。

### 9.4 撤销与重做

- 支持撤销选区创建。
- 支持撤销移动、缩放、删除、命名等操作。
- 支持重做。
- 支持显示当前是否有未保存变更。

## 10. 智能识别能力细节

### 10.1 识别目标

- 独立 icon。
- 按钮图标。
- UI 小组件。
- 游戏道具。
- 表情包小图。
- 雪碧图帧。
- 透明背景上的图形元素。
- 白底或纯色背景上的图形元素。

### 10.2 识别参数

- 背景类型：透明、纯色、自动判断。
- 最小面积。
- 最大面积。
- 最小宽高。
- 最大宽高。
- 边缘检测灵敏度。
- 颜色容差。
- 合并距离。
- 扩展边距。
- 是否保持正方形输出。
- 是否统一输出尺寸。

### 10.3 识别结果编辑

- 删除误识别区域。
- 手动新增漏识别区域。
- 拖拽调整识别框。
- 合并多个框。
- 拆分单个框。
- 批量套用边距。
- 批量统一尺寸。
- 按尺寸或位置筛选识别结果。

### 10.4 智能命名建议

- 根据位置生成名称，例如 row1_col1。
- 根据主色生成名称，例如 blue_icon_01。
- 根据尺寸生成名称，例如 icon_32x32_01。
- 根据原图名生成名称，例如 source_001。
- 后续可接入 OCR 或视觉模型识别语义名称，作为高级功能。

## 11. 自定义尺寸与规格

### 11.1 尺寸输入

- 支持像素单位。
- 支持百分比单位。
- 支持宽高锁定。
- 支持预设尺寸。
- 支持最近使用尺寸记录。

### 11.2 常用预设

- 16 x 16。
- 24 x 24。
- 32 x 32。
- 48 x 48。
- 64 x 64。
- 128 x 128。
- 256 x 256。
- 512 x 512。
- 1024 x 1024。
- 社交媒体常用比例。
- App icon 常用规格。
- Web favicon 规格。
- Android 图标密度规格。
- iOS/iPadOS/macOS App Icon 规格。
- Web/PWA/favicons 规格。

### 11.3 输出缩放

- 支持原尺寸导出。
- 支持 0.5x、1x、2x、3x。
- 支持自定义倍率。
- 支持导出多倍率文件。
- 支持命名后缀，例如 @2x、@3x。

### 11.4 平台化 icon 导出

用户在导出 icon 时，应可以选择目标平台，由系统自动生成对应尺寸、目录结构、文件名和必要的配置文件。平台规格应作为可维护的预设存在，后续可以随 Android、iOS、Web 平台规范变化而更新。

#### 11.4.1 Android 导出预设

- 支持 Android Launcher Icon。
- 支持 Android Adaptive Icon。
- 支持 Android 普通 drawable 图标。
- 支持按 dp 基准尺寸生成不同 density 资源。
- 支持选择 `mdpi`、`hdpi`、`xhdpi`、`xxhdpi`、`xxxhdpi`。
- 支持生成 `mipmap-mdpi`、`mipmap-hdpi`、`mipmap-xhdpi`、`mipmap-xxhdpi`、`mipmap-xxxhdpi` 目录。
- 支持生成 `drawable-mdpi`、`drawable-hdpi`、`drawable-xhdpi`、`drawable-xxhdpi`、`drawable-xxxhdpi` 目录。
- 支持常用倍率：1x、1.5x、2x、3x、4x。
- 支持 Legacy Launcher Icon 常用尺寸：48、72、96、144、192 px。
- 支持 Adaptive Icon 图层尺寸换算：108dp 对应各 density 输出。
- 支持 Adaptive Icon 前景层、背景层、单色层分别导出。
- 支持安全区预览，避免图标主体被系统 mask 裁掉。
- 支持选择输出为 PNG、WebP 或保留源格式。
- 支持 Android 资源命名规则校验，例如小写字母、数字和下划线。

#### 11.4.2 iOS / iPadOS / macOS 导出预设

- 支持 iOS App Icon。
- 支持 iPadOS App Icon。
- 支持 macOS App Icon。
- 支持从一张高分辨率源图生成多尺寸 icon。
- 支持导出 1024 x 1024 px 主图。
- 支持按 `@1x`、`@2x`、`@3x` 生成不同倍率图片。
- 支持生成 Xcode Asset Catalog 可用的 `AppIcon.appiconset` 目录。
- 支持生成 `Contents.json`，作为高级导出选项。
- 支持透明背景检查，提示 App Icon 通常需要完整背景。
- 支持圆角预览，但默认不直接烘焙圆角，避免和系统 mask 冲突。
- 支持深色、浅色或透明外观版本，作为后续增强。

#### 11.4.3 Web / PWA / favicon 导出预设

- 支持 favicon。
- 支持浏览器 tab icon。
- 支持 PWA manifest icons。
- 支持 Apple touch icon。
- 支持 maskable icon。
- 支持常用 favicon 尺寸：16、32、48 px。
- 支持常用 PWA 尺寸：192、512 px。
- 支持输出 `favicon.ico`，作为高级功能。
- 支持输出 PNG、WebP、SVG 引用方案。
- 支持生成 `manifest.json` 的 icons 片段。
- 支持生成 HTML `<link>` 标签片段。
- 支持 maskable 安全区预览，确保关键内容位于安全区域内。

#### 11.4.4 自定义平台规格

- 用户可以新建自定义平台预设。
- 用户可以编辑平台名称、尺寸列表、倍率、文件名规则和目录结构。
- 用户可以为团队或项目保存常用规格。
- 用户可以从 JSON 导入或导出平台规格。
- 支持将同一切片同时导出为 Android、iOS 和 Web 三套资源。
- 支持在导出前展示平台资源清单，包含尺寸、路径、格式和文件名。

## 12. 导出与文件管理

### 12.1 单个导出

- 导出当前选区。
- 导出当前可见选区。
- 导出当前图形裁切结果。

### 12.2 批量导出

- 导出全部选区。
- 仅导出勾选选区。
- 按分组导出。
- 按格式分别导出。
- 打包为 ZIP。
- 按目标平台批量导出 icon 资源。
- 同一 icon 一次性导出 Android、iOS、Web 多端资源包。

### 12.3 导出前检查

- 检查是否存在重名文件。
- 检查是否有空白切片。
- 检查是否有超出图片范围的选区。
- 检查透明区域是否过大。
- 检查导出尺寸是否为 0 或异常值。
- 检查平台 icon 的源图尺寸是否足够。
- 检查 icon 主体是否超出平台安全区。
- 检查 Android 资源文件名是否合法。
- 检查 iOS App Icon 是否存在不符合平台要求的透明区域。

### 12.4 导出后反馈

- 显示导出成功数量。
- 显示失败数量和失败原因。
- 提供打开导出目录按钮，桌面端优先。
- 提供重新导出按钮。
- 提供导出设置保存为预设。

### 12.5 平台资源包

- Android 资源包应支持按 `res/mipmap-*` 或 `res/drawable-*` 目录组织。
- Android Adaptive Icon 资源包应支持前景层、背景层和 XML 配置文件，作为高级功能。
- iOS 资源包应支持 `AppIcon.appiconset` 目录结构。
- iOS 资源包应支持 `Contents.json`。
- Web 资源包应支持 favicon、PWA icons、manifest 片段和 HTML link 片段。
- 多平台资源包应支持 ZIP 打包，并按平台建立一级目录。
- 导出结果应附带一份 `export-report.md` 或 `export-report.json`，记录生成规格和失败项，作为高级功能。

## 13. 项目与预设

### 13.1 项目文件

建议支持保存切图项目，记录：

## 16. 非功能需求

### 16.1 性能

- 常规图片导入应快速响应。
- 大图加载时显示进度或加载状态。
- 智能识别应避免长时间卡死主界面。
- 批量导出应显示进度。
- 网页端应避免一次性占用过高内存。

### 16.2 稳定性

- 图片解析失败时给出清晰提示。
- 大图、损坏文件、不支持格式应有错误处理。
- 批量任务中单个文件失败不应中断全部任务。
- 导出失败应保留用户选区和设置。

### 16.3 隐私

- 网页端默认本地处理图片。
- 不自动上传用户图片。
- 如果后续接入云端 AI 识别，必须明确提示并获得用户确认。
- 项目文件不应包含敏感路径信息，除非用户主动保存。

### 16.4 可访问性

- 支持键盘操作核心流程。
- 按钮和图标提供可读标签。
- 颜色状态不应只依赖颜色区分。
- 深色模式和浅色模式都应保证对比度。

### 16.5 国际化

- 第一阶段可先支持中文。
- 后续建议支持英文界面。
- 尺寸、单位、快捷键提示需要适配不同平台。

## 17. 平台差异需求

### 17.1 桌面端增强能力

- 文件夹批量导入。
- 记住最近打开目录。
- 打开导出目录。
- 本地项目文件保存。
- 更强的大文件处理能力。

### 17.2 网页端限制与补充

- 浏览器权限受限，导出目录控制较弱。
- 适合轻量处理和快速体验。
- 可通过 ZIP 下载批量结果。
- 可通过 IndexedDB 保存最近项目，作为增强功能。

## 18. MVP 范围建议

### 18.1 第一阶段必须做

- 图片导入：PNG、JPG/JPEG、WebP。

- 矩形手动切图。
- 多选区管理。

- PNG/JPG 导出。

- 基础命名规则。

### 18.2 第一阶段建议做

- 去透明边距。

### 18.3 第二阶段做

## 19. 关键边界情况

- 图片没有透明通道，但背景接近纯色。
- 图标之间距离很近，智能识别容易合并。
- 图标内部有镂空透明区域。
- 图片边缘有阴影或发光效果。
- JPG 压缩噪点导致背景不纯。
- 超大图片导致浏览器内存压力。
- 用户画出的选区超出图片边界。
- 导出文件名包含非法字符。
- 批量导出时目标目录已有同名文件。
- 选区尺寸小于 1px 或四舍五入后为 0。

## 20. 后续技术选型方向

此部分仅作为后续评估方向，不代表当前立即实现。

### 20.1 跨平台方案

- Tauri：适合轻量桌面端，前端技术复用网页端。
- Electron：生态成熟，图像处理和桌面能力强，但体积较大。
- Web App + PWA：适合网页端优先，桌面能力有限。

### 20.2 图像处理能力

- Canvas / OffscreenCanvas：适合网页端基础裁切。
- Web Workers：避免智能识别和批量导出阻塞界面。
- WebAssembly 图像库：适合高性能处理。
- 桌面端可接入本地图像处理库提升大图性能。

### 20.3 智能识别方向

- 基于透明 alpha 连通区域分析。
- 基于颜色差异和背景分离。
- 基于边缘检测。
- 基于轮廓检测。
- 后续可接入视觉模型做语义识别和命名。

## 21. 验收标准

### 21.1 基础切图验收

- 用户可以导入一张 PNG 图片。
- 用户可以框选任意矩形区域。
- 用户可以通过拖拽和输入数值调整选区。
- 用户可以导出该选区为 PNG。
- 导出的图片尺寸与选区一致。

### 21.2 批量切图验收

- 用户可以创建多个选区。
- 用户可以在切片列表中查看所有选区。
- 用户可以批量导出所有选区。
- 导出的文件名不冲突。
- 导出结果数量与启用选区数量一致。

### 21.3 网格切图验收

- 用户可以设置固定宽高生成网格。
- 用户可以调整起点和间距。
- 用户可以排除某些格子。
- 导出的图片顺序与预览顺序一致。

### 21.4 智能识别验收

- 对透明背景 icon 合集，系统可以识别出主要独立图形。
- 用户可以删除误识别区域。
- 用户可以手动补充漏识别区域。
- 用户可以批量导出识别结果。

### 21.5 平台 icon 导出验收

- 用户可以选择 Android、iOS 或 Web 作为目标平台。
- 用户可以看到该平台将要导出的尺寸、倍率、文件名和目录结构。
- Android 导出结果包含所选 density 对应的资源文件。
- iOS 导出结果可以生成 `AppIcon.appiconset` 目录。
- Web 导出结果包含 favicon/PWA 常用尺寸。
- 系统可以提示源图分辨率不足、主体超出安全区、文件名不合法等问题。

## 22. 开放问题

- 是否优先做桌面端，还是优先做网页端？
- 是否需要账号系统？
- 网页端是否完全本地处理，还是允许可选云端 AI？
- 是否需要支持 PSD、AI、Sketch、Figma 等设计源文件？
- 是否需要做团队协作和共享预设？
- 是否需要直接输出前端代码片段或 CSS sprite 配置？
- 是否需要支持命令行批处理？
- 是否需要把切图规则保存为模板并复用到自动化流程？
- 平台 icon 规格是内置固定版本，还是支持联网更新？
- Android Adaptive Icon 是否需要完整生成 XML 和前景/背景/单色三层？
- iOS 是否需要覆盖 iPhone、iPad、macOS、watchOS、visionOS 的完整图标族？
- Web 是否需要同时生成 manifest、HTML link 标签和 service worker 辅助文件？

## 23. 建议的第一版产品定义

第一版建议定位为“本地优先的跨平台图片切图工作台”，重点解决用户从一张或多张位图中快速、准确、批量提取素材的问题。

第一版不建议一开始就做复杂 AI 语义识别、账号系统和云同步。更稳妥的路线是先完成可靠的画布、选区、导出、网格、固定尺寸和透明区域分析，再逐步加入智能识别 icon、自定义形状和高级批处理。

建议第一版主打以下能力：

- 手动矩形切图足够精确。
- 多选区批量导出足够顺畅。
- 固定尺寸和网格切图覆盖 sprite sheet 场景。
- 去透明边距和基础自动识别提升效率。
- Web favicon/PWA 常用尺寸导出作为第一版平台化能力。
- 桌面端与网页端共享核心界面和图像处理逻辑。
